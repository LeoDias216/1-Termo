# 📚 Termos - Material de Aprendizado

**Repositório de Exercícios e Projetos - 1º e 2º Termo**

## 📋 Descrição do Projeto

Este repositório contém uma coleção completa de exercícios, projetos e materiais didáticos desenvolvidos durante o 1º e 2º termo de estudos. O projeto abrange o aprendizado de programação em **Python** (1º termo) e **JavaScript** com desenvolvimento web (2º termo), incluindo conceitos de lógica de programação, estruturas de dados, sistemas de backend e interfaces HTML/CSS.

---

## 🛠️ Tecnologias Utilizadas

### 1º Termo
- **Python 3.x** - Programação imperativa, POO básica, estruturas de dados
- **Paradigma**: Programação procedural e orientada a objetos

### 2º Termo
- **JavaScript (Node.js)** - Lógica de programação, entrada/saída com `readline-sync`
- **HTML5** - Markup para interfaces web
- **CSS3** - Estilização (conforme necessário)
- **npm** - Gerenciador de pacotes
- **Dependências**: 
  - `readline-sync` - Entrada interativa no terminal

 ### Resumo das aulas e atividades

 ### 1º termo: Python

 - **Aula 2 - `segundo.py`**: tipos numéricos e strings, operações matemáticas, área de triângulo, calculadora, IMC, entrada de dados e cadastro simples.
 - **Aula 3 - `terceiro.py`**: condicionais `if`, `elif` e `else`, cálculos, maioridade, categorias, gorjeta, sucessor/antecessor e descontos.
 - **Aula 5 - `quinto.py`**: laços `for` e `while`, listas, tabuada, estoque, produção, temperatura, pressão e menu de Pokémon.
 - **Aula 6 - `sexto.py`**: criação de funções, parâmetros, retorno, leitura de dados e cálculo do dobro.
 - **Aula 7 - `setimo.py`**: revisão somativa com exercícios sobre veículos, autonomia, conversão, médias, carga, atrasos, fretes, combustível, pneus e rastreamento.
 - **Aula 8 - `oitavo.py`**: métodos de strings, leitura e escrita de arquivos e operações com `os`. A execução cria `arquivo.txt` e `arquivo.py` no diretório de execução.
 - **Aula 9 - `Projeto.py`**: especificação comentada de um estacionamento com 500 vagas, acesso por TAG ou ticket, tarifas, desconto e perda de ticket. O arquivo não contém uma implementação executável.
 - **Aula 10 - `decimo.py`**: primeira interface Tkinter com janela, texto, botão e mensagem.
 - **Aula 11 - `onze.py` e `onze2.py`**: cadastro gráfico de nome e idade; o segundo arquivo é uma janela de login/cadastro incompleta.
 - **Aula 12 - `doze.py`**: interface gráfica relacionada a nome e ano de nascimento, ainda sem cálculo funcional da idade.
 - **Atividades**: avaliações de lógica e logística, exercícios de listas, condicionais e laços, interfaces Tkinter e comparação de código procedural com funções em `Clean Code.py`.
 - **Projetos**: jogo de terminal contra um Orc, sistema de brigada, interface Tkinter de brigada, simulação de cancelas, elevador e interface gráfica de jogo com imagens.

 ### 2º termo: Node.js

 - **Backend/Aula1**: análise de crédito, contador de 0 a 100, menu de padaria e tabuada interativa.
 - **Backend/Aula2/funcoes.js**: média, objetos de produto, conversão Celsius/Fahrenheit, descontos e estoque. A subpasta `Desafios` trabalha aposentadoria, parcelas e área de terrenos.
 - **Backend/Laços**: acesso a arrays, média e aprovação de lotes por peso e acumulador de preços.
 - **Backend/Aula3_sistemas**: sistema modular de oficina com orçamento, garantia e desconto; módulo de logística com frete, seguro e prazo.
 - **Desafios**: aluguel de veículo, desconto em restaurante, escolha entre gasolina e álcool, classificação de nadadores, aprovação de empréstimo e contagem decimal. Também há versões em Python e HTML.

 ### HTML, LIMA e SmartCoffee

 - **AULA1**: introdução a HTML, links, estilos inline e exercícios de página.
 - **AULA2**: títulos, parágrafos, abreviações, formatação e bloco de código.
 - **AULA4**: imagens, favicon, fundos e dimensionamento de imagens.
 - **AULA5**: páginas de HTML/CSS, blog, currículo e exemplos de HTML semântico.
 - **Projeto**: protótipo estático do SmartCoffee com páginas de clientes, delivery, estoque, funcionários, pagamento, pedidos, produtos e programa de fidelidade. As páginas não possuem backend, persistência ou lógica de cadastro.

 ### Banco de dados

 `2 TERMO/BCD` contém scripts SQL para biblioteca, clínica médica e SmartCoffee, além de documentação RTF. A pasta `Modelos` contém modelos conceituais de biblioteca, cafeteria e relacionamentos em BrModelo. Os scripts SQL devem ser revisados antes de uso, pois alguns incluem comandos destrutivos, tipos incompletos ou sintaxe apenas demonstrativa.

 ## Como executar com Node.js

 1. Instale o Node.js, que inclui o `npm`.
 2. Abra um terminal na raiz do repositório e instale a dependência:

 ```powershell
 cd "2 TERMO"
 npm install
 ```

 3. Execute um arquivo a partir da pasta `2 TERMO`:

 ```powershell
 node Backend/Aula1/Aula1.js
 node Backend/Aula1/contador.js
 node Backend/Aula1/padaria.js
 node Backend/Aula1/tabuada.js
 node "Backend/Aula2/funcoes.js/ex1.js"
 node "Backend/Aula2/funcoes.js/Desafios/ds1.js"
 node Backend/Laços/array.js
 node Backend/Laços/array2.js
 node Backend/Aula3_sistemas/oficina/app.js
 node Backend/Aula3_sistemas/oficina/Logistica/sistemaEntrega.js
 node Desafios/Desafio1.js
 node Desafios/Desafio_contagem.js
 ```

 Os programas que usam `readline-sync` solicitam dados no terminal. `contador.js` e `Desafio_contagem.js` não dependem de entrada interativa. Para executar outro arquivo, mantenha-se em `2 TERMO` e informe o caminho relativo ao arquivo no comando `node`.

 ## Outros arquivos

 Para executar Python, use `python "caminho\do\arquivo.py"`. As interfaces Tkinter precisam de uma instalação do Python com Tkinter; `interface jogo.py` também requer Pillow. Os arquivos HTML podem ser abertos diretamente no navegador ou servidos localmente, por exemplo:

 ```powershell
 python -m http.server 8000 --directory "2 TERMO/LIMA/Projeto"
 ```

 Depois, acesse `http://localhost:8000`.

```bash
npm install
```

```bash
cd "2 TERMO/Backend"
node Aula1/Aula1.js
node Aula1/contador.js
```

### **HTML (2º Termo - LIMA)**

Abrir os arquivos HTML diretamente no navegador:
- Windows: `start "2 TERMO/LIMA/Projeto/index.html"`
- Linux/Mac: `open "2 TERMO/LIMA/Projeto/index.html"`

Ou através de um servidor local:
```bash
# Usar Python
cd "2 TERMO/LIMA/Projeto"
python -m http.server 8000
# Depois acessar: http://localhost:8000

# Ou usar Node.js com http-server
npm install -g http-server
http-server "2 TERMO/LIMA/Projeto"
```

### Clonar o repositório:

