# 📚 Termos - Material de Aprendizado

**Repositório de Exercícios e Projetos - 1º e 2º Termo**

---

## 📋 Descrição do Projeto

Este repositório contém uma coleção completa de exercícios, projetos e materiais didáticos desenvolvidos durante o 1º e 2º termo de estudos. O projeto abrange o aprendizado de programação em **Python** (1º termo) e **JavaScript** com desenvolvimento web (2º termo), incluindo conceitos de lógica de programação, estruturas de dados, sistemas de backend e interfaces HTML/CSS.

---

## 🛠️ Tecnologias Utilizadas

### 1º Termo
- **Python 3.x** - Programação imperativa, POO básica, estruturas de dados
- **Paradigma**: Programação procedural e orientada a objetos

### 2º Termo
- **JavaScript (Node.js)** - Lógica de programação, entrada/saída com `readline-sync`
- **HTML5** - Markup para interfaces web
- **CSS3** - Estilização (conforme necessário)
- **npm** - Gerenciador de pacotes
- **Dependências**: 
  - `readline-sync` - Entrada interativa no terminal

## 📝 Resumo dos Exercícios por Aula

### **1º TERMO - PYTHON**

#### **Aula 2 - Tipos de Dados e Operadores Básicos**
- Tipos primitivos (int, float, string)
- Operadores aritméticos e de concatenação
- Operações com números e textos
- Print e entrada de dados

#### **Aula 3 - Estruturas Condicionais**
- Comando `if`, `else`, `elif`
- Expressões booleanas
- Operadores lógicos (and, or, not)
- Tomada de decisão em programas

#### **Aula 5 - Loops e Iterações**
- `while` loop
- `for` loop com range
- Uso de break e continue
- Contadores e acumuladores

#### **Aula 6 - Funções**
- Definição de funções
- Parâmetros e retorno
- Variáveis locais e globais
- Reutilização de código

#### **Aula 7 - Listas e Arrays**
- Criação e manipulação de listas
- Indexação e slicing
- Métodos de lista (append, remove, sort)
- Iteração em listas

#### **Aula 8 - Manipulação de Strings**
- Operações com strings
- Métodos de string (upper, lower, split, join)
- Formatação de strings
- Busca e substituição

#### **Aula 9 - Projeto: Sistema de Estacionamento**
- Projeto integrado com todos os conceitos
- Simulação de sistema de vagas
- Cálculo de tarifas
- Controle de acesso (TAG vs Ticket)

#### **Aula 10, 11, 12 - Tópicos Avançados**
- Revisão e consolidação de conceitos
- Estruturas mais complexas
- Boas práticas de código

#### **ATIVIDADES**
- **ATIVIDADE SOMATIVA.py**: Exercícios de avaliação com problemas reais
  - Registro de veículo
  - Cálculo de autonomia de combustível
  - Conversor de moeda (Dólar para Real)
- **ATIVIDADE SOMATIVA2.py**: Segunda bateria de exercícios
- **Clean Code.py**: Implementação de boas práticas
- **LISTA 1.py e Lista3.py**: Exercícios variados

#### **PROJETOS**
- **brigada.py**: Sistema de controle de brigada
- **brigadainterface.py**: Interface para sistema de brigada
- **cancelas.py**: Sistema de controle de cancelas
- **elevador.py**: Simulação de elevador com vários andares
- **interface jogo.py**: Interface para jogo interativo
- **apresentacaojogo.py**: Apresentação e gameplay

- **Desafios_volta2.html**: Interface HTML para desafios

#### **LIMA - Projeto: SmartCoffee (Sistema de Delivery)**

Projeto integrado HTML com 9 módulos:

1. **index.html** - Página inicial da SmartCoffee
   - Apresentação da cafeteria
   - Navegação para todos os módulos

2. **Clientes.html** - Sistema de cadastro de clientes
   - Formulário de registro
   - Gerenciamento de perfil

3. **Delivery.html** - Acompanhamento de entrega
   - Rastreamento em tempo real
   - Status do pedido

4. **Estoque.html** - Gestão de estoque
   - Produtos disponíveis
   - Controle de quantidade

5. **Funcionarios.html** - Cadastro de funcionários
   - Dados da equipe
   - Informações de contato

6. **Pagamento.html** - Formas de pagamento
   - Opções (débito, crédito, PIX, etc.)
   - Configuração de pagamento padrão

7. **Pedidos.html** - Realização de pedidos
   - Carrinho de compras
   - Confirmação de pedido

8. **Produtos.html** - Catálogo de produtos
   - Menu da cafeteria
   - Descrições e preços

9. **Programa_fidelidade.html** - Sistema de pontos
   - Acúmulo de pontos
   - Resgate de recompensas

## 🚀 Como Executar

### **Python (1º Termo)**

#### Executar arquivo individual:
```bash
python "1 TERMO/Aula2/segundo.py"
python "1 TERMO/ATIVIDADES/ATIVIDADE SOMATIVA.py"
```

#### Executar projetos:
```bash
python "1 TERMO/Aula9/Projeto.py"
python "1 TERMO/Projetos/brigada.py"
python "1 TERMO/Projetos/elevador.py"
```

### **JavaScript (2º Termo)**

#### Instalar dependências:
```bash
cd "2 TERMO/Backend"
npm install
```

#### Executar arquivo individual:
```bash
cd "2 TERMO/Backend"
node Aula1/Aula1.js
node Aula1/contador.js
node Aula1/tabuada.js
node Laços/array.js
node Desafios/Desafio1.js
```

#### Exemplos de execução:
```bash
# Sistema de crédito
node "2 TERMO/Backend/Aula1/Aula1.js"

# Contador interativo
node "2 TERMO/Backend/Aula1/contador.js"

# Tabuada interativa
node "2 TERMO/Backend/Aula1/tabuada.js"

# Arrays
node "2 TERMO/Backend/Laços/array.js"
```

### **HTML (2º Termo - LIMA)**

Abrir os arquivos HTML diretamente no navegador:
- Windows: `start "2 TERMO/LIMA/Projeto/index.html"`
- Linux/Mac: `open "2 TERMO/LIMA/Projeto/index.html"`

Ou através de um servidor local:
```bash
# Usar Python
cd "2 TERMO/LIMA/Projeto"
python -m http.server 8000
# Depois acessar: http://localhost:8000

# Ou usar Node.js com http-server
npm install -g http-server
http-server "2 TERMO/LIMA/Projeto"
```

## 📌 Instruções de Git

### Clonar o repositório:
```bash
git clone <URL_DO_REPOSITORIO>
cd Termos
```

### Ver status:
```bash
git status
```

### Adicionar alterações:
```bash
git add .
git add "arquivo_especifico.py"
```

### Fazer commit:
```bash
git commit -m "Descrição das alterações"
```

### Enviar para repositório remoto:
```bash
git push origin main
```

### Atualizar repository local:
```bash
git pull origin main
```

### Ver histórico de commits:
```bash
git log
git log --oneline
```

### Criar nova branch:
```bash
git checkout -b nome-da-branch
git push origin nome-da-branch
```

### Voltar a commits anteriores:
```bash
git checkout <hash_do_commit>
git reset HEAD~1  # Desfazer último commit mantendo alterações
```
